# SOM CANET · Fitxa ràpida de Sanity Studio

| Vull… | Obre… |
| --- | --- |
| Crear una notícia | **Notícies de l’Arxiu → +** |
| Canviar la portada | **Portada i dades de contacte** |
| Editar una pàgina | **Pàgines principals →** tria la pàgina |
| Afegir text, una foto o un botó a una pàgina | **Blocs de contingut**, dins de la pàgina |
| Pujar un PDF | **Revistes i documents PDF → +** |
| Actualitzar l’equip o afegir un vídeo | **Persones de l’equip** o **Vídeos de l’arxiu** |

**Notícia nova.** Escriu el títol, prem **Genera** a l’adreça, afegeix el text i tria **Actualitat** al **Filtre de l’Arxiu**.

**Abans de publicar.** Obre **Edició visual** i comprova com queda. Per fer una prova, deixa el contingut com a esborrany.

**Durant la demostració.** Després de prémer **Publica**, executa [Publish to GitHub Pages](https://github.com/aminch18/som-canet-web/actions/workflows/pages.yml) a `main` i espera que acabi abans de recarregar el web.
